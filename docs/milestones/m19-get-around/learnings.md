# M19 · Get around

## Learnings

- S82's long shop name ran into the book's title only once a mock held a long one, in its third round, so the Bought page took four. Mocks now seed each field's longest real value. [Plan slice](../../../.claude/skills/plan-slice/SKILL.md#mocks)
- Seeded copies showed no prices in S81's first mocks: a copy is priced only when it is certainly the book, which takes a declared ISBN. The mock rules say so. [Plan slice](../../../.claude/skills/plan-slice/SKILL.md#mocks)
- S82 started from Letterboxd's diary, and the close copy read as borrowed until its months became typed headings and its day moved beside the price. A reference is now mocked in the app's own pieces too. [Plan slice](../../../.claude/skills/plan-slice/SKILL.md#mocks)
- #72 promised a default scope, and US-only turned out to run through the daily check, the want list's price, the email and the counts. It left the slice for #288. Planning a setting now asks what reads the value it replaces. [Plan slice](../../../.claude/skills/plan-slice/SKILL.md#questions)
- Breaking S83's code on purpose through the stash reverted a file's own changes, caught only by checking the tree before pushing. The rule now names copying the file aside. [CONTRIBUTING](../../../CONTRIBUTING.md#testing)
- S85 made a plain address mean the last choices made, so every link had to name its choices outright, or Cheapest could never be picked again. [Design system](../../design-system.md#components)
